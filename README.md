# 🔍 OrangeHRM Testing Project

## 📖 Project Overview

This is a personal software testing project for the OrangeHRM open-source system.
The project covers both Manual Testing and Automation Testing using Selenium with Java.
The objective of this project is to simulate a real-world testing process including planning, designing test cases, executing tests, reporting bugs, and building automation framework.

## 🎯 Scope of Testing

### 1️⃣ Admin Module

+ Manage Users
+ Manage Job Titles

### 2️⃣ PIM Module

+ Employee List
+ Add Employee

### 3️⃣ Leave Module
+ Leave Types
+ Leave Period
+ Add Leave Entitlement

## 🏗 Automation Framework Design
The automation framework is designed using:
+ Page Object Model (POM)
+ Base Test configuration
+ TestNG execution control
+ Maven dependency management

## 🚀 How to Run Automation Tests
1. Clone this repository
2. Open project in IntelliJ IDEA
3. Install Maven dependencies
4. Run `testng.xml`
5. View results in `test-output` folder
